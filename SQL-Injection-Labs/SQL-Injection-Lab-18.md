Now, the output of the SQLi does not appear on the Page. It is called Blind SQLi. But the good thing is that its giving verbose error. So we may be able to get the password of the users.

We can use a function called CAST (). This function allows to convert one data type to another data type.

We will try to generate different errors using CAST() function.

Lets create the payload

***F1Uaa3I8M0PH1S0u’ AND CAST((SELECT 1) as int) --***




This time we dont get any error. It means this query is completely valid.
